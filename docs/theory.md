# Теоретичні основи та план роботи

## Мета
Навчити три нейромережі різної складності визначати **марку авто за фото**, порівняти їх
та пояснити, чому складніші моделі працюють краще.

```
Фото авто → [нейромережа] → "BMW" (ймовірність 92%)
```

---

## 1. Дані

**Датасет:** Stanford Cars — 16 185 фото, 196 моделей авто, 49 марок
(дзеркало Hugging Face `tanganke/stanford_cars`).

1. **Агрегація класів** — моделі об'єднуються в марки («BMW M3 Coupe 2012» + «BMW X5 SUV 2007» → «BMW»).
2. **Фільтрація** — залишаються марки, що мають щонайменше 300 фото: **20 марок, 12 681 фото, 153 моделі**.
   Марки з малою кількістю прикладів (Tesla, Porsche, Mazda тощо, ~80 фото) відкинуто — на них неможливо надійно навчитися.
3. **Обрізка не виконується** — дзеркало не містить bounding box, а оригінальні анотації недоступні.
   На більшості фото авто займає центральну частину кадру, тому це прийнятно.
4. **Стратифіковане розбиття** (частка кожної марки однакова в усіх частинах, `random_state=42`):
   - **train (70%, 8 876)** — навчання;
   - **validation (15%, 1 902)** — контроль під час навчання, вибір найкращої епохи;
   - **test (15%, 1 903)** — фінальна перевірка, використовується один раз.
5. **Дисбаланс класів** — від 314 (Buick) до 1 799 (Chevrolet) фото, співвідношення ≈ 5.7.
   Тому основна метрика — macro F1, додатково розглядається зважена функція втрат.

---

## 2. Представлення зображення

- Зображення — тензор `висота × ширина × 3` (канали R, G, B). Для 224×224 це $224 \cdot 224 \cdot 3 \approx 150\,000$ чисел.
- **Resize** — приведення до розміру 224×224.
- **Нормалізація** — значення пікселів зводяться до середнього 0 та одиничного стандартного відхилення (статистики ImageNet).
- **Аугментація** (тільки train) — випадкові віддзеркалення, повороти, обрізки, зміна яскравості. Збільшує різноманітність даних і зменшує перенавчання.
- **Batch** — дані подаються порціями (наприклад, по 32 зображення).

---

## 3. Цикл навчання (спільний для всіх моделей)

```
для кожної епохи:
    для кожного батчу з train:
        1. прогноз              (forward pass)
        2. обчислення помилки    (loss)
        3. обчислення градієнтів (backpropagation)
        4. оновлення ваг         (optimizer step)
    оцінка на validation
    якщо результат кращий — зберегти модель
```

| Термін | Значення |
|---|---|
| **Ваги** | параметри мережі, які підлаштовуються під час навчання |
| **Softmax** | перетворює вихід мережі на ймовірності: $P(k \mid x) = \dfrac{e^{z_k}}{\sum_j e^{z_j}}$ |
| **Крос-ентропія** | функція втрат: $L = -\log P(\text{правильний клас} \mid x)$ |
| **Backpropagation** | обчислення градієнтів втрат за кожною вагою |
| **Optimizer (AdamW)** | адаптивний градієнтний спуск з weight decay |
| **Learning rate** | розмір кроку оновлення ваг |
| **Епоха** | один повний прохід по навчальній вибірці |

Навчання виконується на GPU Apple M4 Pro через PyTorch MPS (з автоматичним вибором `cuda` → `mps` → `cpu`).

## 4. Модель 1 — проста CNN з нуля 🟢

Згорткова нейромережа з випадково ініціалізованими вагами.

```
Фото → [Conv → BatchNorm → ReLU → MaxPool] × 4 → Global Pooling → Dropout → Linear → марка
```

- **Згортка (convolution)** — фільтр 3×3 ковзає по зображенню й реагує на локальні візерунки. Ваги фільтрів навчаються.
- **Ієрархія ознак** — ранні шари виявляють краї й кути, глибші — фари, колеса, решітку радіатора.
- **ReLU** — $\max(0, z)$, вносить нелінійність.
- **Pooling** — зменшує просторовий розмір, зберігаючи найважливіше.
- **BatchNorm** — нормалізує активації між шарами, стабілізує навчання.
- **Dropout** — випадково вимикає нейрони під час навчання, зменшує перенавчання.

**Очікування:** базова модель (baseline); обмежена малою кількістю даних і невеликою глибиною.

---

## 5. Модель 2 — ResNet18 🟡

Глибока CNN з 18 шарів (He et al., 2015).

**Залишкові з'єднання (skip connections):**

$$
y = F(x) + x
$$

Вхід блоку додається до його виходу, що дозволяє градієнту вільно проходити через глибоку мережу
та розв'язує проблему згасання градієнта.

**Transfer learning:**
- мережа попередньо навчена на **ImageNet** (1,2 млн зображень, 1000 класів) і вже вміє виділяти загальні візуальні ознаки;
- останній шар замінюється на новий з $N$ виходами (кількість марок);
- **етап А** — основа заморожена, навчається лише новий класифікатор;
- **етап Б (fine-tuning)** — розморожується вся мережа, донавчання з малим learning rate.

**Очікування:** суттєвий приріст точності завдяки перенесенню знань.

## 6. Модель 3 — Vision Transformer (ViT) 🔴

Архітектура трансформера (Dosovitskiy et al., 2020), перенесена з обробки тексту на зображення. Згорток немає.

1. **Patches** — зображення 224×224 ділиться на 196 фрагментів 16×16 («слова»).
2. **Patch embedding** — кожен фрагмент лінійно проєктується у вектор.
3. **Positional embedding** — додається інформація про положення фрагмента.
4. **[CLS] токен** — спеціальний токен, що агрегує інформацію про все зображення; з нього робиться прогноз.
5. **Self-attention** — кожен фрагмент обчислює, наскільки важливі для нього всі інші:

$$
\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V
$$

   На відміну від CNN, яка бачить лише локальне сусідство, трансформер одразу враховує глобальний контекст.
6. Кілька блоків трансформера поспіль → класифікаційна голова.

ViT не має вбудованих припущень про структуру зображень (inductive bias), тому з нуля потребує
мільйонів зображень. Використовується попередньо навчений **ViT-Small / DeiT-Small** з fine-tuning.

**Очікування:** найвища точність, але найбільші обчислювальні витрати.

## 7. Перенавчання та регуляризація

| Стан | Опис | Ознака на графіках |
|---|---|---|
| **Underfitting** | модель надто проста | низька точність на train і validation |
| **Overfitting** | модель запам'ятала train | висока точність на train, значно нижча на validation |
| **Баланс** | добре узагальнення | криві train і validation близькі |

Методи: аугментація, Dropout, weight decay, early stopping, learning rate scheduler (cosine annealing).

## 8. Оцінювання

| Метрика | Опис |
|---|---|
| **Accuracy** | частка правильних прогнозів |
| **Top-3 accuracy** | правильна марка серед трьох найімовірніших |
| **Precision** | $\dfrac{TP}{TP + FP}$ — точність прогнозів класу |
| **Recall** | $\dfrac{TP}{TP + FN}$ — повнота знаходження класу |
| **F1** | $2 \cdot \dfrac{P \cdot R}{P + R}$ |
| **Macro F1** | середнє F1 по всіх класах — стійке до дисбалансу |

**Графіки:**
1. Розподіл класів і приклади зображень.
2. Криві навчання (loss / accuracy по епохах).
3. Confusion matrix.
4. Приклади помилкових прогнозів.
5. Grad-CAM (CNN) та attention maps (ViT) — інтерпретація рішень.
6. Порівняльна таблиця: точність, F1, час навчання, кількість параметрів.
